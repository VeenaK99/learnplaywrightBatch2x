# Chapter 3: Identifier Rules and Naming Conventions

This folder covers JavaScript identifier naming rules and various naming conventions.

## Files

- **06_Identifier_rules.js** - Rules for valid JavaScript identifiers
- **07_Identifiers_past_02.js** - Naming conventions including:
  - camelCase
  - PascalCase
  - snake_case
  - SCREAMING_SNAKE_CASE
  - kebab-case
- **08_comment.js** - How to write comments in JavaScript
- **windows_shortcut.md** - Useful Windows keyboard shortcuts

## Naming Conventions Covered

| Convention | Example | Use Case |
|------------|---------|----------|
| camelCase | `myVariableName` | Variables, functions |
| PascalCase | `MyClassName` | Classes, constructors |
| snake_case | `my_variable_name` | Variables (Python style) |
| SCREAMING_SNAKE_CASE | `MY_CONSTANT` | Constants |
| kebab-case | `my-file-name` | File names, CSS classes |
