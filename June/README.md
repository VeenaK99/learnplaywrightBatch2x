# June - JavaScript Learning Repository

This repository contains JavaScript exercises and concepts organized by chapters.

## Folder Structure

| Chapter | Topic | Description |
|---------|-------|-------------|
| [Chapter_01_Basics](Chapter_01_Basics/) | JavaScript Basics | Introduction to JavaScript, variables, and commands |
| [Chapter_02_javaScriptConcepts](Chapter_02_javaScriptConcepts/) | Core Concepts | Fundamental JavaScript concepts |
| [Chapter_03_Identifier_rules](Chapter_03_Identifier_rules/) | Naming Conventions | Identifier rules and naming conventions (camelCase, PascalCase, snake_case, etc.) |
| [Chapter_04_JavaScriptConcepts](Chapter_04_JavaScriptConcepts/) | Scope & Hoisting | var, let, const, function scope, block scope, and hoisting |
| [Chapter_05_Literals](Chapter_05_Literals/) | Literals | Numbers, strings, null, undefined, booleans, and template literals |
| [Chapter_06_Operators](Chapter_06_Operators/) | Operators | Arithmetic, comparison, logical, ternary, nullish, increment/decrement, modulus, exponentiation, and type operators |
| [Chapter_07_if_else](Chapter_07_if_else/) | Conditional Statements | If-else, if-else-if, nested conditions, grade calculator, leap year |
| [Chapter_08_Switch_statements](Chapter_08_Switch_statements/) | Switch Statements | Switch, default, grouping, fall-through, real-time examples |
| [Chapter_09_User_input](Chapter_09_User_input/) | User Input | prompt(), prompt-sync, number input, validation, menu systems |
| [Chapter_10_Loops](Chapter_10_Loops/) | Loops | for, for-in, for-of, forEach, while, do-while, interview questions |
| [Chapter_11_Arrays](Chapter_11_Arrays/) | Arrays | Create, access, modify, add/remove, search, iterate, transform, sort, slice, concat, and array checking |
| [Chapter_12_Functions](Chapter_12_Functions/) | Functions | Function declarations, return/no-return types, template literals, function expressions, arrow functions, IIFE, default parameters, rest parameters, spread, scope, closures, higher-order functions, and pure vs impure functions |
| [Chapter_13_Strings](Chapter_13_Strings/) | Strings | String creation (quotes, backticks, String(), String.raw), properties, indexing, searching/checking, palindrome, and anagram |
| [Chapter_14_Objects](Chapter_14_Objects/) | Objects | Nested arrays/matrices (test-case data), iterating rows and cells with nested loops, and star patterns (forward, reverse, pyramid) |
| [Chapter_16_Callback](Chapter_16_Callback/) | Callback Functions | Passing functions as arguments, synchronous and asynchronous callbacks (setTimeout), and the nested "pyramid of doom" |

## Quick Navigation

- **Chapter 1** - Start here if you're new to JavaScript
- **Chapter 2** - Dive deeper into core concepts
- **Chapter 3** - Learn proper naming conventions and identifier rules
- **Chapter 4** - Understand scope, variable declarations, and hoisting
- **Chapter 5** - Master literals: numbers, strings, booleans, null, undefined, and template literals
- **Chapter 6** - Practice with operators: arithmetic, comparison, logical, ternary, and more
- **Chapter 7** - Conditional statements: if-else, grade calculator, leap year
- **Chapter 8** - Switch statements: grouping, default, fall-through behavior
- **Chapter 9** - User input handling with prompt and validation
- **Chapter 10** - Loops: for, for-in, for-of, forEach, while, do-while
- **Chapter 11** - Arrays: create, access, modify, search, iterate, transform, sort, slice, concat, and array checks
- **Chapter 12** - Functions: declarations, return types, template literals, function expressions, arrow functions, IIFE, default & rest parameters, spread, scope, closures, higher-order functions, and pure vs impure functions
- **Chapter 13** - Strings: creation methods, properties, indexing, searching/checking, palindrome and anagram
- **Chapter 14** - Objects: nested arrays/matrices, nested loops, and star patterns
- **Chapter 16** - Callback functions: functions as arguments, sync vs async callbacks, and the pyramid of doom

## How to Use

Each chapter folder contains:
- Individual `.js` files with exercises
- A `README.md` with detailed information about the files

Open any `.js` file in your code editor or browser console to run the examples.
